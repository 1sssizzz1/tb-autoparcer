# TB Market Watch

Локальное веб-приложение на React и Go для просмотра предложений Steam Community Market и market.dota2.net по аркане Terrorblade **Fractal Horns of Inner Abysm**.

Приложение объединяет предложения двух площадок, показывает цену в выбранной валюте и призматический самоцвет. У каждого лота отображается источник; ссылка открывает соответствующую страницу предмета.

## Запуск

Требуются Go 1.24+ и Node.js 20+ с npm. Установить Node.js на macOS через Homebrew можно командой `brew install node`.

### Через Docker

Требуется установленный и запущенный Docker Desktop. На macOS его можно установить через Homebrew:

```sh
brew install --cask docker
open -a Docker
```

Дождитесь, пока Docker Desktop запустится, затем в терминале из папки проекта соберите образ и запустите контейнер:

```sh
cd "/Users/1sssizzz1/AI/tb autoparcer"
docker compose up --build -d
```

Откройте <http://localhost:8080>. Для просмотра логов бэкенда используйте `docker compose logs -f`; остановить контейнер можно командой `docker compose down`. В браузере откройте инструменты разработчика (`⌥⌘I` в Safari или `⌥⌘J` в Chrome) и вкладку Console, чтобы увидеть подробности ошибки API или пустого ответа.

#### Если вместо лотов отображается ошибка

Покажите последние сообщения сервера:

```sh
docker compose logs --since=10m --tail=100
```

Строка `Steam Market response: status=429` означает, что upstream ответил ограничением на запрос, отправленный приложением. `market request deferred by local cooldown` означает, что приложение ждёт перед очередным запросом после предыдущего 429 и не обращается к Steam. `Steam Market response contained no exact item match` означает, что upstream ответил успешно, но в результатах нет предмета с ожидаемым точным названием. В браузерной Console ищите записи с префиксом `[TB Market Watch]`.

Если Docker сообщает, что порт 8080 уже занят, остановите локально запущенный Go-сервер или измените левую часть `8080:8080` в `compose.yaml`, например на `8081:8080`; тогда приложение будет доступно на <http://localhost:8081>.

### Запуск без Docker

Все команды ниже запускаются в приложении Terminal.

1. Перейдите в папку проекта и соберите интерфейс:

   ```sh
   cd "/Users/1sssizzz1/AI/tb autoparcer/frontend"
   npm install
   npm run build
   ```

   Сборка нужна перед первым запуском и после изменений интерфейса.

2. Откройте второй терминал и запустите Go-сервер:

   ```sh
   cd "/Users/1sssizzz1/AI/tb autoparcer"
   go run .
   ```

3. Откройте <http://localhost:8080>.

Чтобы остановить сервер, нажмите `Ctrl+C` в терминале, где выполняется `go run .`.

### Разработка интерфейса

Запустите Go-сервер, как описано выше. В другом терминале выполните:

```sh
cd "/Users/1sssizzz1/AI/tb autoparcer/frontend"
npm run dev
```

Откройте адрес, который напечатает Vite (обычно <http://localhost:5173>). Запросы `/api` будут перенаправляться на Go-сервер.

## Данные и ограничения

- Steam Market загружается по `Fractal Horns of Inner Abysm` с фильтрами Terrorblade и Arcana; бэкенд получает отдельные предложения постранично.
- market.dota2.net запрашивается с фильтрами Arcana и Terrorblade, после чего оставляются записи `Fractal Horns of Inner Abysm`. Для определения самоцвета запрашивается публичная страница предмета; если страница не содержит распознаваемого гема, отображается «Не указано». Ссылка ведёт на страницу предмета market.dota2.net, а не на конкретную сделку продавца.
- Для каждого предложения показываются его источник, идентификатор, цена, количество и самоцвет. Если одна из площадок недоступна, приложение сохраняет доступные данные и показывает предупреждение о неполной загрузке.
- Главная страница группирует лоты в интерактивные карточки самоцветов: каждая показывает цвет, минимальную текущую цену и количество предложений. Нажатие на карточку прокручивает к лотам с выбранным самоцветом. Ниже доступны карточки отдельных предложений, текстовый поиск, сортировка и фильтры.
- Цену можно переключать между рублями, долларами США и евро. Пересчёт выполняется по последнему доступному курсу ЦБ, который кэшируется на 12 часов. Если сервис курсов временно недоступен, приложение всё равно показывает исходную валюту предложения, а недоступные валюты временно скрываются. Для Steam ссылка содержит ID предложения в параметрах `listingid` и `detail`, чтобы открыть нужный лот.
- Для публичных цен не нужны пароль Steam, API-ключ или cookies аккаунта. Бэкенд получает обычную анонимную cookie при открытии публичной страницы предмета; не передавайте приложению данные аккаунта.
- Успешный полный ответ кэшируется сервером в Docker volume на 5 минут, после чего интерфейс обновляет данные. При временной ошибке источника возвращаются доступные данные с предупреждением; ранее сохранённый полный ответ остаётся в кэше. При `HTTP 429` Steam приложение учитывает `Retry-After`; если заголовка нет, повторяет попытку через минуту. API различает upstream `HTTP 429` и локальную паузу приложения (`HTTP 503`).

## Структура Go-бэкенда

- `main.go` — запуск приложения и конфигурация HTTP-сервера.
- `api.go` — HTTP API и раздача собранного интерфейса.
- `market_service.go` — объединение результатов, кэширование, состояние и конвертация валют.
- `market_sources.go` — HTTP-клиенты и парсинг Steam Market и market.dota2.net. Для market.dota2.net используется отдельный HTTP/2-клиент; Steam продолжает работать через свой транспорт.

Если браузер не открывает страницу, убедитесь, что Go-сервер запущен. Если порт 8080 уже занят, остановите другой экземпляр приложения сочетанием `Ctrl+C`, затем снова выполните `go run .`.

Целевая страница предмета: [Fractal Horns of Inner Abysm в Steam Market](https://steamcommunity.com/market/listings/570/Fractal%20Horns%20of%20Inner%20Abysm?category_Hero=npc_dota_hero_terrorblade&category_Rarity=Rarity_Arcana).
